# إتاحة APK اللاعب عبر GitHub Releases

## الغرض

هذه التعليمات مخصصة لنسخة **Card Clash** للاعبين فقط. ملف `eas.json` يعرّف ملف `player` على أنه APK داخلي قابل للتثبيت، بينما نسخة `developer` مخصصة للتشخيص ولا ينبغي رفعها لصفحة التحميل العامة.

| العنصر | نسخة اللاعب | نسخة المطور |
|---|---|---|
| الاسم الظاهر | Card Clash | Card Clash Dev |
| ملف البناء | `player` | `developer` |
| صفحة Releases العامة | نعم | لا |
| شارة التشخيص | لا | نعم |

## خطوات النشر

ابدأ من واجهة المشروع واضغط **Publish** بعد اختيار ملف `player`. يولّد ذلك APK من مسار البناء المعتمد دون استهلاك موارد بيئة التطوير. بعد اكتمال البناء، نزّل ملف APK وسمّه بالصيغة التالية:

```text
Card-Clash-v1.0.0.apk
```

بعد ذلك، افتح صفحة **Releases** في المستودع، وأنشئ إصداراً جديداً بالوسم `v1.0.0`، والصق محتوى `docs/release-notes/v1.0.0.md` في وصف الإصدار. أرفق ملف APK، ثم انشر الإصدار. يصبح زر التحميل متاحاً للاعبين من صفحة Releases مباشرة.

> لا ترفع `Card Clash Dev` إلى صفحة التحميل العامة. هذه النسخة تتضمن عميل تطوير وشارة تشخيص LAN مخصصين للاختبار.

## قائمة التحقق قبل النشر

- [ ] تم اختيار ملف `player` لا `developer`.
- [ ] تم تثبيت APK على هاتف Android فعلي وفتح اللعبة بنجاح.
- [ ] تم التحقق من اللعب المحلي Wi‑Fi بين جهازين إذا كانت الميزة ضمن الإصدار.
- [ ] اسم الملف يتضمن رقم الإصدار ولا يحتوي مسافات.
- [ ] ملاحظات الإصدار تذكر الميزات الرئيسية والقيود المعروفة.
- [ ] تم رفع APK وحده، وليس ملفاً مفكوكاً أو نسخة مطور.
