# Card Clash v1.0.0

## تحميل Android

نزّل ملف `Card-Clash-v1.0.0.apk` من الأصول المرفقة ثم افتحه على جهاز Android. قد يطلب النظام السماح بالتثبيت من المتصفح أو مدير الملفات المستخدم للتنزيل.

## ما يتضمنه الإصدار

يتضمن هذا الإصدار معارك بطاقات عربية بالوضع الأفقي، خصوماً بالذكاء الاصطناعي، غرفاً خاصة، مطابقة تنافسية، ودعوات أصدقاء. كما يتضمن وضع لعب محلي Wi‑Fi يكتشف الغرف داخل الشبكة المحلية ويستخدم اتصال TCP مباشر بين الهاتفين.

## ملاحظات التشغيل

يتطلب وضع Wi‑Fi المحلي اتصال الهاتفين بنقطة الشبكة نفسها، وقد يحتاج تعطيل Client Isolation في إعدادات الراوتر. لا تخلط هذه النسخة مع نسخة `Card Clash Dev` المخصصة للمطور.
