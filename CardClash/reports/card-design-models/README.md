# نماذج Full Art Tactical

يعرض هذا المجلد نموذجين بصريين بنسبة `3:4` صُمما كمرجع لتطوير كروت Card Clash على الهاتف. كلاهما يحافظ على الفن كخلفية كاملة، ويضع اسم الشخصية والبيانات الأساسية في منطقة سفلية مظللة ومقروءة.

| الملف | الندرة | الملاحظات البصرية |
|---|---|---|
| `normal-card-full-art-tactical.png` | عادي | إطار فضي رفيع، شارة زرقاء صغيرة، ومعلومات منظمة في شريط سفلي؛ الفن يظل محور البطاقة. |
| `legendary-card-full-art-tactical.png` | أسطوري | إطار ذهبي رفيع مع تفاصيل زوايا محدودة، شارة ذهبية، وتسلسل بصري يرفع حضور الندرة دون إخفاء الرسم. |

التحقق البصري: يظهر الاسم والإحصاءات العربية بوضوح في كلا النموذجين، وتبقى النسب العمودية مناسبة لكرت جوال. سيحتاج التطبيق الفعلي إلى إظهار هذه النصوص من بيانات الكرت بدلاً من إدراجها داخل الصورة.

## نسخة حقول القتال

النسخ المحدثة هي `normal-card-combat-fields.png` و`legendary-card-attack-defense-only.png`. تضيف هذه النماذج حقول القتال الأساسية داخل نظام بصري ثابت: شارة العنصر في الزاوية العلوية اليسرى، وشارة الندرة في الزاوية العلوية اليمنى، وخانتان سفليتان متساويتان للهجوم والدفاع.

| جزء الواجهة | حقل `Card` المستخدم | طريقة العرض |
|---|---|---|
| الاسم | `nameAr` و`nameEn` | اسم عربي بارز، مع اسم إنجليزي اختياري أصغر تحته. |
| فن الكرت | `finalImage` أو `imageUrl` | صورة كاملة تغطي الكرت؛ لا تُكتب الأرقام داخل ملف الفن في التطبيق. |
| الهجوم | `attack` | أيقونة سيف، تسمية «هجوم»، ورقم كبير. |
| الدفاع | `defense` | أيقونة درع، تسمية «دفاع»، ورقم كبير. |
| الندرة | `rarity` | شارة علوية مستقلة، مثل «عادي» لـ `common` و«أسطوري» لـ `legendary`. |
| العنصر | `element` | شارة علوية مستقلة، مع الاسم العربي واللون من `ELEMENT_COLORS`. |

للاستخدام داخل التطبيق، تعامل مع الصور الجديدة كمراجع أسلوبية أو كروت نموذجية فقط. ينبغي أن تبقى شارات الندرة والعنصر والإحصاءات مكوّنات React Native مرسومة فوق الفن، لتتبدل قيمها مع أي بطاقة من بيانات اللعبة الحالية دون تصميم صورة جديدة لكل رقم.

## قالب React Native الجاهز

أضيف المكوّن `components/game/full-art-tactical-card.tsx`. يقرأ مباشرة حقول `Card` الحالية: `nameAr` و`nameEn` و`finalImage` أو`imageUrl` و`attack` و`defense` و`rarity` و`element`. يعرض شارة العنصر والندرة في الأعلى، ثم الاسم، ثم شريط الهجوم والدفاع في الأسفل مع دعم العربية واتجاه RTL.

```tsx
import { FullArtTacticalCard } from '@/components/game/full-art-tactical-card';

<FullArtTacticalCard card={card} width={220} />
```

استخدم `width={180}` للعرض الضيق في الهاتف و`width={220}` للعرض الافتراضي. لا يتطلب القالب إضافة حقول جديدة إلى نوع `Card`، لذلك يمكن إدخاله تدريجياً في شاشة اختيار الكروت أو المعاينة قبل استبدال العرض القديم في كامل اللعبة.

## معيار الكرت الأسطوري المعتمد

يعتمد الكرت الأسطوري شكل `legendary-card-attack-defense-only.png` مرجعاً بصرياً: فن كامل داخل إطار ذهبي رفيع، شارة العنصر في أعلى اليسار، شارة «أسطوري» في أعلى اليمين، اسم واضح فوق الشريط السفلي، وشريط موحّد يعرض الهجوم والدفاع فقط. لا تظهر الصحة في واجهة الكرت.

تم تطبيق هذه القواعد في `LuxuryCharacterCardAnimated`، وهو المكوّن المستخدم فعلياً في شاشة المعركة والاختيار والمعرض. عند تمرير كرت له `rarity: 'legendary'`، سيعرض تلقائياً شارة العنصر المقابلة وشريط الإحصاءات الذهبي ذي الخانتين مع بقاء الفيديو والصوت والتأثيرات الحالية دون تغيير.
