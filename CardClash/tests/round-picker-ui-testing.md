# اختبارات واجهة اختيار الجولات

يتحقق الملف `card-selection-round-picker.test.ts` من أن نافذة ترتيب البطاقات لا تعود إلى قائمة رأسية طويلة عندما يزيد عدد الجولات.

## التشغيل

```bash
pnpm vitest run tests/card-selection-round-picker.test.ts
pnpm test
```

## السيناريوهات المغطاة

| السيناريو | التحقق |
|---|---|
| 5 جولات | لا تحتاج الشبكة إلى تمرير داخل نافذة الهاتف العمودية. |
| 18 جولة | تتحول الشبكة إلى قائمة قابلة للتمرير داخل مساحة ثابتة. |
| 30 جولة | يبقى عرض أزرار الجولات صالحاً ولا تتجاوز النافذة أبعاد الشاشة. |
| الهاتف العمودي | تتكدس معاينة الكرت أعلى الشبكة لتجنب تجاوز العرض. |
| الوضع الأفقي | تستعمل الشبكة المساحة الموجودة بجانب الكرت. |

## إضافة سيناريو جديد

أضف حالة إلى `tests/card-selection-round-picker.test.ts` باستعمال `getRoundPickerLayout` و`doesRoundPickerNeedScroll`. يجب اختيار أبعاد جهاز فعلية، ثم التحقق من عرض الزر، عدد الأعمدة، والحاجة إلى التمرير. تحمل عناصر الواجهة المعرّفات `round-picker-modal` و`round-picker-grid` و`round-picker-round-{number}` لتستخدمها لاحقاً في اختبارات Playwright التفاعلية.
